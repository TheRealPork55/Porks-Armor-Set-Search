# What is it?
Angel's Armor Set Search is a modern day Athena's Armor Set Search replacement.
# Scope
Angel's ASS aims to provide services similar to Athena's ASS for Monster Hunter Wilds. In future updates, the project will retroactively expand to most Monster Hunter titles of the past, wrapped up into one single app. Future updates will also add any new Monster Hunter titles, as well as the currently unnamed Monster Hunter Wilds expansion DLC.
# What Can I Expect?
Angel's ASS contains every armor piece, non-Artian/Gogmaartian weapon, and non-random Talisman in the game, and will make sets of armor based on given parameters. You will be provided with a full list of drops required to build the armor, as well as Transcend it if that option was selected.
